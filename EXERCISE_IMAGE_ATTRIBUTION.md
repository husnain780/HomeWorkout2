# Exercise image attribution

All 30 exercise visuals in `app/src/main/res/drawable` are original vector illustrations created for HomeWorkout.

They use the app brand palette (mint background, emerald accents, navy figure) so the library works fully offline, with a consistent aspect ratio and no third-party photography.

Original six movements reuse the established resource names:

- `push_up`
- `bodyweight_squat`
- `plank`
- `jumping_jacks`
- `forward_lunges`
- `mountain_climbers`
