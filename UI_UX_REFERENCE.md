# HOME WORKOUT — OFFICIAL UI/UX REFERENCE

Status: LOCKED DESIGN DIRECTION

The attached 17-screen reference image is the visual and UX target for
the HomeWorkout application.

The existing functionality and architecture must NOT be removed while
implementing this design.

========================================
VISUAL DESIGN SYSTEM
========================================

Overall Style:
- Premium modern fitness application
- Clean, minimal, professional
- Light UI with strong visual hierarchy
- White / very light backgrounds
- Dark navy / charcoal text
- Fresh green as the primary action color
- Soft green gradients used sparingly
- Rounded cards
- Rounded buttons
- Thin subtle borders
- Soft shadows
- Large readable typography
- Consistent spacing
- Professional fitness photography / illustrations
- No unnecessary visual clutter
- No excessive glow
- No random colors
- No generic AI-dashboard appearance

Primary visual language:
- White surfaces
- Dark text
- Green primary actions
- Light gray secondary surfaces
- Green progress indicators
- Green active navigation state
- Consistent rounded components
